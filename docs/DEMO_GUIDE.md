# Demo guide

1. Start the API, then start the frontend.
2. Register a citizen account and submit the Hinglish example in the Playground.
3. Observe preprocessing, attention, Word2Vec and extractive-summary outputs.
4. Create an explicit demo administrator with `scripts/create_demo_admin.py`
   after setting its two required environment variables.
5. Log in as that administrator, review the complaint and update its status.
6. Generate the civic TF-IDF baseline from the protected research endpoint.
